# FAR (Forget About Recharge) — Brand System & Home Page Redesign

## 1. Project Objective & Core Mission
**FAR** (**Forget About Recharge**) empowers users to never spend money on mobile recharge bills again. By engaging with verified creator content (YouTube subscriptions, video promos, web offers) and inviting friends through the **2-Hour 4X Viral Multiplier Challenge**, users earn credits ($1\text{ Credit} = ₹1\text{ Recharge}$) that are automatically redeemed for genuine 4G/5G data packs and unlimited talktime on **Jio, Airtel, Vodafone Idea (Vi), and BSNL**.

## 4. Remade Home Page Architecture

1. **Hero Section**:
   - Live 4X challenge notification pill with amber glow.
   - High-energy headline: *"Never Pay For Mobile Recharges Again. Forget About Recharge."*
   - Direct CTA buttons: `⚡ Claim 25 Free Welcome Credits` (lightning pulse) + `See How It Works`.
   - Micro trust checks: 100% Free Forever, No Bank Details Needed, Instant Operator Delivery.
   - **Interactive 3D Phone Mockup**: Floating smartphone displaying real-time wallet credits, live operator recharge delivery confirmation, and quick-earn tasks.

2. **Live Activity Proof Ticker**:
   - Auto-cycling live feed showing real users across India redeeming packs (e.g. Jio ₹299, Airtel ₹349, Vi ₹19, BSNL ₹107) with green verified indicators.
   - Aggregate statistics: **185,000+** active users, **₹4.2M+** recharges sent, **99.8%** success rate.

3. **2-Hour 4X Multiplier Challenge**:
   - Visual progress card demonstrating how 25 credits turn into 100 credits upon referring 2 friends within 2 hours.

4. **Interactive Recharge Savings Calculator**:
   - Allows users to select operator (Jio, Airtel, Vi, BSNL) and plan type (Monthly, Quarterly, Booster) to immediately see their projected yearly cash savings (e.g. ₹3,588 / year).

5. **Genuine Operator Plans Preview**:
   - Tabbed view showing real Indian prepaid packs (1GB emergency data, 1.5GB/day 28-day plans, 84-day super savers). Demonstrates that $1\text{ Credit} = ₹1\text{ Value}$.

6. **The 3-Step Lightning Flow**:
   - Step 1: Sign up & grab 25 free credits.
   - Step 2: Complete micro-tasks or unlock 4X viral bonus.
   - Step 3: Instant recharge dispatched directly to the user's phone via SMS.

7. **Ways to Earn Credits**:
   - YouTube verified channel subscriptions (Google API backed), video promos, 30s web discovery, daily streaks, tier level-ups.

8. **Community Reviews**:
   - Verified feedback from students and professionals with operator tags.

9. **Interactive FAQ Accordion**:
   - Clear explanations covering zero-cost model, delivery speed, and supported circles.

10. **High-Voltage Final Banner**:
    - Concluding call-to-action with instant signup trigger.
